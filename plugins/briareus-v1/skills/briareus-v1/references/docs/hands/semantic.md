# Serena Hand — optional semantic navigation

**Catalog:** `serena`. **Source:** [Serena README](../../services/hands/serena/README.md).

This is an **optional** independently deployed code-navigation/refactoring Hand. It indexes authorized existing workspace folders and starts child language-server sessions subject to bounded process and memory limits. Its own toolchain and provisioning contract are documented by its owner.

**Operational status:** Serena is intentionally stopped in the current deployment. Its presence in the source catalog or MCP connection guide is not an instruction to start/restart it. Use other available source tools for current work unless a future operator decision authorizes Serena.

A Serena `project_id` and registration do not justify a separate Git clone. Reuse the canonical repository and, when necessary, its Git-linked worktrees. Follow [workspace policy](../operations/git-and-worktrees.md). Language-server toolchains are operator-controlled, not automatically installed into new project clones.
