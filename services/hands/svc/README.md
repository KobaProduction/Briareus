# SVC/provider implementation boundary

Provider/repository behavior belongs to the Hands MCP module contract.
Node Gateway exposes a separate endpoint; Node Access/Cedar owns exact
Project/session effect decisions. Human identity belongs to infrastructure.

Source placement and health do not establish deployment or callable tool
readiness. Adapt source/packaging through qualified ownership/dependency
changes with existing data, app identities and rollback preserved.

See [SVC contract](../../../docs/hands/svc/README.md) and
[cutover](../../../docs/operations/service-layout-transition.md).
